An LLM on a chip with 512 KB of fast memory
  • 28.9M parameters on an ESP32-S3, offline, 9.88 tokens per second; the 25M-parameter lookup table stays in slow flash and each token reads about 450 bytes of it: slvDev/esp32-ai README
  • 87% of the model is the Per-Layer Embeddings table (an idea from Google's Gemma 3n); the dense transformer core is 556,416 parameters, 2%: model card
  • Trained only on short children's stories, so it can't answer questions or follow instructions: same model card · TinyStories (arXiv 2305.07759)
  • The board also has 8 MB of PSRAM and 16 MB of flash; the 512 KB is the chip's fast internal SRAM (README)

100B parameters on one CPU: Microsoft's BitNet
  • A 100B BitNet b1.58 model on a single CPU at 5-7 tokens per second; up to 6.17x faster and up to 82.2% less energy on x86 CPUs: microsoft/BitNet README

  • Supported models: BitNet-b1.58-2B-4T (2.4B parameters) and the Falcon3 family up to 10B, per the same README
